Do not add a `resume/` route here in Astro.

`/about/resume/` is populated at deploy time by the GitHub Actions workflow
(.github/workflows/deploy-site.yml), which copies the latest static build
output from the separate `resume` repo into `dist/about/resume/` *after*
`astro build` runs. Adding an Astro page/route at this path would conflict
with that step.
